Installation

Follow these steps to set up KantorApp on your server.

1. Environment Setup

Ensure your server meets the following requirements:

  • PHP 8.2 or later
  • MySQL 8.0+ / MariaDB 10.5+
  • BCMath, Ctype, Fileinfo, JSON, Mbstring, OpenSSL, PDO PHP Extensions
2. Step-by-Step CLI
# Clone current repository
git clone https://your-repository-url.git
cd kantorapp

# Install PHP dependencies
composer install --no-dev --optimize-autoloader

# Install JS dependencies
npm install
npm run build

# Setup .env
cp .env.example .env
php artisan key:generate

# Run DB Migration & Seed
php artisan migrate --seed
php artisan db:seed --class=RoleSeeder

User Roles

Super Admin

Complete control. Manage master shifts, create locations, promote admins, and configure global branding settings.

Location Admin

Branch-specific management. Approves tasks, manages local rosters, tracks branch attendance, and overrides shifts.

HR

Manages Jobdesks, Task Catalogs, Employee Contracts, and Employee Mutations across all divisions.

Employee

Mobile-friendly portal to clock in/out, complete tasks, request overtime, and track work recaps.

Attendance & GPS

KantorApp uses dual-verification for attendance to prevent fraud:

1. Geofencing (GPS)

Every location has a configurable GPS coordinate and radius (e.g., 50 meters). Employees must be within this radius to clock in.

2. Biometric Selfie

During check-in and check-out, the system captures a real-time selfie from the browser camera. This photo is attached to the attendance record for admin verification.

3. Device Fingerprinting

The system logs the unique Device ID and Browser Agent to prevent employees from using multiple devices for unauthorized check-ins.

Shift & Roster System

The shift system is designed for flexibility and fairness.

Key Concept: Master Shifts (Templates) are created by Super Admin, but then assigned and "Overridden" at the Location level by Location Admins.
  • Anti-Overlap: System prevents assigning overlapping shifts to the same user.
  • Health Guard: Automatically warns if a "Morning" shift is assigned immediately after a "Night" shift.
  • Weekly Roster: A massive calendar view allows admins to drag-and-drop shifts for the whole week.

Task & Jobdesk

Task management is tied to Jobdesks. An employee assigned to a "Developer" jobdesk can only pick tasks from the "Development" catalog.

Point System Logic

The system supports Points based tasks. For example, assign a task worth 2 Points, and the app automatically calculates a 60 Minute duration (configurable).

Slot Management

Large tasks are split into Progress Slots. A task is only "Completed" once all its slots are approved with valid link/photo evidence.
